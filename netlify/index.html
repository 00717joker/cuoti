          配置好 GitHub Token 后，每次添加/练习会自动同步题库到 GitHub 仓库的 data/db.json。

          如果同步后题数翻倍，点此去重。以"学科+章节+题号+小节"为唯一键，保留信息最全的。

          检测所有 gh: 链接的图片是否真的存在于仓库，缺失时若本机 IDB 有原始 blob 会自动补传。建议在"最早上传这些图的手机/电脑"上点此按钮效果最佳。

          🚨 当前版本紧急修复通道（v3.9.0 在线升级）

          如果发现"同步按钮点了没反应 / 图片 404 / 没有出现上面的一键修复按钮"，说明你访问的 GitHub Pages 版本落后（gh-pages 上的 index.html 被误写过）。点下方按钮即可从官方仓库拉取最新修复版源码并 用你已保存的 GitHub Token 直接覆盖 gh-pages + main，无需手动粘贴 Token / 命令行。
